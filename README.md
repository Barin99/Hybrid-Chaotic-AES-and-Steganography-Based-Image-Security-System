# Hybrid-Chaotic-AES-and-Steganography-Based-Image-Security-System
Tech Stack: MERN (React.js, Node.js, Express.js, MongoDB), Python, PyCryptodome. Developed a secure web application for image encryption, steganography, and retrieval. Implemented AES-256 (CBC), LSB steganography, and chaotic pixel scrambling for multi-layer security.
